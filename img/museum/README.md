# 2D Interactive Museum Assets Directory

This directory contains all the visual and map assets used by the 2D museum game.

## Directory Structure

- `img/museum/tilesets/` - Sourced PNG tilesets (Sprout Lands & Bitglow Cozy 16x16).
- `img/museum/characters/` - Spritesheets for the player character and NPCs.
- `img/museum/maps/` - JSON map exports from Tiled or custom maps.

## Populating Sourced Assets (GATE 3)

Please download the following free asset packs and place their PNG files under `img/museum/tilesets/`:

1. **Sprout Lands - Asset Pack** (by Cup Nooble):
   - Link: https://cupnooble.itch.io/sprout-lands-asset-pack
   - Sourced files: Interior floor, walls, and basic rustic furniture sheets.
2. **Pixel Interior - Cozy 16x16** (by Bitglow):
   - Link: https://bitglow.itch.io/pixel-interior-cozy-16x16-living-room-kitchen
   - Sourced files: Living room and kitchen furniture (sofas, rugs, bookshelves, fireplaces).
